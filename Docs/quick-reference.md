# 早見表（クイックリファレンス）

対戦中に見る用。詳細は [[rulebook]] を参照。

## 勝利条件

- 敵の部隊員を撃破：**2点**（ドローン・カメラ・タレットは0点）
- ターン終了時にネクサスマスを保持：**1点**（試合合計3点まで）
- 全滅か、制限ターン終了時に合計点が多い側の勝ち。同点なら残存HP合計で判定

## 1ターンの流れ

1. 全員同時に指示（装備の持ち替え → 移動 → 行動）
2. イニシアチブ順（敏捷性 → 機動力 → ランダム）に1体ずつ解決：移動 → 行動
3. 出番前に撃破されたユニットの指示は無効（ULT不発・EX消費なし）
4. ターン終了処理：毒・状態・ネクサス判定

## 計算式

```
命中率(%) ＝ 武器の命中率 ＋ (自分の精密 − 相手の敏捷性) ÷ 2 ＋ 補正　※5〜95%に制限
ダメージ ＝ (攻撃力 ＋ 武器の威力) ÷ 2 × 100 ÷ (100 ＋ 相手の防御力 ＋ 防具補正)　※最低1
移動マス ＝ 機動力 ÷ 5（最低1）
目視範囲 ＝ 5 ＋ 索敵 ÷ 20　マス（高台の上では +2）
```

## 主な補正

| 状況 | 効果 |
|---|---|
| 移動しなかった | 命中 +10%、ダメージ +10% |
| 遮蔽あり（壁・低障害物が対象の手前） | 被射撃の命中 −10% |
| スナイパーライフルで距離1〜2 | 命中 −20% |
| ハンドガンで距離1 | 命中 +10% |
| ショットガン | 距離1で威力 +10、距離3で威力 −5 |
| 高台の上から射撃 | 命中 +10% |

## 連携追撃

- 同じ敵へ同陣営 **2人目の単体攻撃が命中** → **30%** で発動
- 最初に攻撃した味方が追撃：通常攻撃ダメージの **50%**（必中）
- 1ターンに部隊全体で1回まで。範囲攻撃・ドローン・二刀流の2回目は数えない

## EXとULT

- EXポイント：初期1、保持上限2。移動してEXマスに止まると +1（居座りでは増えない）
- ULT：EXを1消費。出番前に倒れると不発

## 状態異常

| 状態 | 効果 | 解除 |
|---|---|---|
| 毒 | 行動時に固定5ダメージ | メディカルキット、ヒールポイント |
| ビーコン | 位置がバレて壁抜きで撃たれる。迷彩中でも見える | 「切除」（1ターン＋自傷5） |
| 行動不能 | 1ターン、移動も行動も不可 | 時間経過 |

## 地形早見

| マス | 要点 |
|---|---|
| 壁 | 移動不可・射線を遮る。耐久30 |
| 水場 | 移動不可。射線・目視は通る |
| 低い障害物 | 移動不可。射線は通る。耐久20 |
| 橋 | 耐久40。壊れると移動不可に。破壊時、上にいたユニットは20ダメージ＋押し出し |
| 高台 | 目視 +2、射撃命中 +10%。隠蔽効果は得られない |
| ブッシュ | 姿が隠れる（射線は通る）。攻撃するとバレる |
| ヒールポイント | 止まるとHP15回復＋毒解除。1回で消滅 |
| EXマス | 止まるとEX +1（ULT用の資源のみ、得点にはならない） |
| ネクサスマス | マップ中央の得点マス。ターン終了時に保持で1点（試合合計3点まで） |
| 焦土 | 破壊された跡。移動可・遮蔽なし |
