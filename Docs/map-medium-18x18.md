# 中サイズマップ案「中央運河」18×18

ルールブック v0.2 の中サイズ（標準）用マップ。**180度回転対称**で設計してあるため、どちらの陣営が先手・後手でも地形条件は完全に互角。

## 地形の内訳（324マス中）

| 種類 | マス数 | 備考 |
|---|---|---|
| 壁 | 48（14.8%） | 建物・廃墟として配置。壁＋ブッシュで約19%が遮蔽 |
| ブッシュ | 14 | 初期配置エリア内にも1マスずつある（隠れてスタート可能） |
| 運河（移動不可） | 16 | 中央を横切る2行。渡れるのは橋だけ |
| 橋 | 4（2カ所×2マス） | 中央の9〜10列。破壊されると渡河不可になる |
| EXマス | 2 | 橋の南北すぐ（8行9列／11行10列）。橋頭堡の争奪戦が起きる位置 |
| ヒールポイント | 2 | 両翼の奥（5行15列／14行4列）。前線から離れていて、戻るか攻め続けるかの判断が出る |
| 初期配置エリア | 各18マス（3行×6列） | 自陣端の中央 |

## 設計意図

- **中央運河と2つの橋**：マップを南北に分断し、渡河ポイントを中央の橋2カ所に絞った。橋を押さえた側がEXマス（橋の両側すぐ）にアクセスできる。グレネードランチャーで橋を破壊すると、相手の進路を大きく制限できる（ただし自分の退路も消える）。
- **3つの進攻ルート**：
  1. **中央ルート**：最短だが橋がボトルネック。EXマス争奪の主戦場
  2. **東ルート（右翼）**：ヒールポイント側。建物（4〜6行・10〜13列付近）が多く近接戦向き
  3. **西ルート（左翼）**：ブッシュが多く、ステルス・奇襲向き。回り込むと相手の裏を取れる
- **狙撃ラインの抑制**：最長の直線視界でも、建物と運河沿いの柱（9〜10行・3列と16列）で分断されるため、スナイパー（射程8）が一方的に撃ち続ける場所はない。運河の南北の開けた場所（8行・11行付近）は撃ち合いの危険地帯。
- **情報戦の余地**：ブッシュ14マスと建物の陰で、索敵の低いユニット同士だと「どこにいるか分からない」状態が序盤に発生する。センサーや偵察役の価値が出る配置。

## プレイ感の想定

- 1〜2ターン目：両軍とも橋と翼へ前進。偵察で相手の布陣を探る
- 3〜5ターン目：EXマスと橋を巡る中央の撃ち合い、翼では迂回と迎撃
- 6ターン目以降：ULTの撃ち合いと、ヒールポイントへ下がるかどうかの消耗戦判断
- 制限12ターンで決着がつかない場合は、EXマスを長く保持した側がポイント計算前に精神的に有利（保持自体は無得点なので、最後は撃破ポイントの殴り合いになる）
