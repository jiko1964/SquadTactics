# 中サイズマップ案「中央運河」18×18

ルールブックの中サイズ（標準）用マップ。**180度回転対称**で設計してあるため、どちらの陣営が先手・後手でも地形条件は完全に互角。

**ネクサスは中央の橋の4マス**（9〜10行・9〜10列）が兼ねる。ターン終了時に中央橋の上に止まっている陣営がネクサスポイントを得る（ルールブック1章・7章）。中央橋が破壊されると、そのマスはネクサスでもなくなる。西の橋（3〜4列）と東の橋（15〜16列）はネクサスではない（ただの渡河ポイント）。

## 地形の内訳（324マス中）

| 種類 | マス数 | 備考 |
|---|---|---|
| 壁 | 44（13.6%） | 建物・廃墟として配置。壁＋ブッシュで約18%が遮蔽 |
| ブッシュ | 14 | 初期配置エリア内にも1マスずつある（隠れてスタート可能） |
| 運河（移動不可） | 24 | マップを端から端まで横切る2行。渡れるのは3カ所の橋だけ |
| 橋 | 12（3カ所×4マス） | 西3〜4列・中央9〜10列・東15〜16列。破壊されるとそのルートは渡河不可になる。**ネクサスマスを兼ねるのは中央の4マスのみ**（保持で得点、破壊されると得点源も消える） |
| EXマス | 2 | 橋の南北すぐ（8行9列／11行10列）。橋頭堡の争奪戦が起きる位置 |
| ヒールポイント | 2 | 両翼の奥（5行15列／14行4列）。前線から離れていて、戻るか攻め続けるかの判断が出る |
| 初期配置エリア | 各18マス（3行×6列） | 自陣端の中央 |

## 設計意図

- **中央運河と3つの橋**：運河はマップを端から端まで横切って南北に分断し、渡河ポイントは西・中央・東の橋3カ所のみ。全ルートが橋なので、グレネードランチャーで橋を破壊すれば相手の進路そのものを封鎖できる（ただし自分の退路も消える）。橋3本に対して守備側は3体しかいないため、全部の橋は守り切れず、どこを本命にするかの読み合いになる。中央橋を押さえた側がEXマス（橋の両側すぐ）にアクセスできる。
- **3つの進攻ルート**：
  1. **中央ルート**：最短だが中央橋がボトルネック。橋そのものがネクサス（得点源）なので、得点の主戦場でもある。橋を落とせば相手の得点源を消せるが、自軍も点を取れなくなる
  2. **東ルート（右翼）**：東の橋を渡る。ヒールポイント側。建物（4〜6行・10〜13列付近）が多く近接戦向き
  3. **西ルート（左翼）**：西の橋を渡る。ブッシュが多く、ステルス・奇襲向き。回り込むと相手の裏を取れる
- **狙撃ライン**：運河沿いの柱はなくなったため、8行・11行の川岸沿いは視界が長く通り、対岸同士の撃ち合いが起きやすい（水場は射線を遮らない）。ただし内陸は建物で分断されるため、スナイパー（射程8）が一方的に撃ち続ける場所はない。運河の南北の開けた場所（8行・11行付近）は撃ち合いの危険地帯。
- **情報戦の余地**：ブッシュ14マスと建物の陰で、索敵の低いユニット同士だと「どこにいるか分からない」状態が序盤に発生する。センサーや偵察役の価値が出る配置。

## プレイ感の想定

- 1〜2ターン目：両軍とも橋と翼へ前進。偵察で相手の布陣を探る
- 3〜5ターン目：EXマスと橋を巡る中央の撃ち合い、翼では橋の争奪と迎撃
- 6ターン目以降：ULTの撃ち合いと、ヒールポイントへ下がるかどうかの消耗戦判断
- 得点の主軸はキル（2点）。拮抗した場合は、中央橋（ネクサス）の保持で稼いだ最大2点が勝敗を分ける
